How the crew is found Spagitty looks on PATH for command-line agents and runs each once to read its version. Only agents that run headless from a terminal can join; editor plug-ins can't.
Who gets which task A task goes to its suggested agent. If that one is busy, the first free agent whose skills match the task's kind takes it. An agent never reviews its own work.
Another agent Any CLI that takes a prompt as an argument or on stdin and exits when it is done.
